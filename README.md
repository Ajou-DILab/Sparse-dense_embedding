## WSD Training Dataset
WordNet is a large lexical datasets made by Princeton University. Nouns, verbs, adjectives and adverbs are grouped into sets of cognitive synonyms(synsets). SemCor 3.0, a large-scale sense-
annotated corpus, is used to train the context encoder. SemCor includes 226,036 annotated word instances across diverse text domains. Please visit https://wordnet.princeton.edu/ to check more details and download datasets.

To evaluate WSD performance and compare against WSD baselines, we used benchmark datasets from the Senseval and SemEval competitions. These include Senseval-2 (SE2), Senseval-3 (SE3), SemEval-2007 (SE07), SemEval-2013 (SE13), and SemEval-2015 (SE15). WSD Benchmark Datasets can download in https://.
